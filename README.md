# Armando Mariscos — Landing Page

Landing page de un solo archivo para Armando Mariscos, restaurante de Hermosillo, Sonora.

## En vivo

https://sensational-starship-db17ca.netlify.app

## Qué incluye

- Menú con 4 platillos y precios
- Horario y ubicación
- Botón de WhatsApp
- Formulario de contacto (Netlify Forms)

## Cómo publicarla

Arrastra la carpeta con `index.html` a Netlify Drop, o conecta este repo a Netlify.
